# chunky-bacon

Another name for **[chunky_bacon](https://github.com/Largo/chunkybacon/tree/main/gem/chunky_bacon)**, the companion gem of the
Ruby course [Learn Ruby with Chunky Bacon](https://github.com/Largo/chunkybacon).

`gem install chunky-bacon` installs chunky_bacon; `require "chunky-bacon"`
loads it. Use whichever name you like - they are the same library.
